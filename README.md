# Harmit Patel — Personal Portfolio

A responsive, static personal portfolio built with semantic HTML, modern CSS, and a small amount of vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. No build step or package installation is required.

## Before publishing

- Confirm the email address and social profile URLs in `index.html`.
- Add verified skills and real project links when ready. The current page deliberately avoids claiming technologies or project experience that have not been provided.
- Confirm the public site URL in the Open Graph metadata.

## Structure

- `index.html` — page content, metadata, navigation, and sections
- `css/styles.css` — responsive layout, design system, and interaction states
- `js/main.js` — mobile navigation and dynamic copyright year
- `images/` — original artwork and profile assets
